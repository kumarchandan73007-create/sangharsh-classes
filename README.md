# SUNGHARSH CLASSES — v2

**Study Smart. Prepare Better. Succeed Together.**

A working school-notes website for **Class 8, Class 9 and Class 10 only**.

## Included
- Professional student homepage
- Class 8 / 9 / 10 filters
- Subject + material-type filters
- Search
- PDF open/download
- Admin login
- PDF upload (25 MB)
- Note metadata: title, chapter, class, subject, type, description
- Delete notes
- Persistent local JSON storage
- Responsive mobile design

## Run
Install Node.js 18+.

```bash
npm install
npm start
```

Open:
- Student site: http://localhost:3000
- Admin: http://localhost:3000/admin

Default local admin:
- Username: `john bhai`
- Password: `chandan@`

Change this before publishing online. You can set `ADMIN_USER` and `ADMIN_PASSWORD` as environment variables.
